# Closed, once — why these are not open items

> Material `AGENTS.md` § *Open* used to carry prose for although it was resolved, retracted or
> judged a phantom gap. An open item is one that can still change a decision; a verdict is
> history, and history kept in the injected layer costs every session.
- **HTTP token-count 面 —— 已落码，全量门 + 活体三查双绿（10-14 关闭，门禁说明保留）**（Router/）— 旧缺口(10-13 活体): `POST /v1/count-tokens` 只认 `{model,prompt}`(OpenAI/Anthropic 惯例字段 `input`/`messages` 一律 `400 Coding key `prompt` not found.`)，`POST /v1/messages/count_tokens` = **404**(Anthropic SDK 预算前置调用必挂)，且 404 提示语「endpoints via GET /v1/capabilities」背后无索引。落码: ① `CountTokensRequest` 改手解，收 `prompt` / `input`(string｜`[String]`｜`[{role,content}]`) / `messages`(+`system` 字符串或 text-block)，precedence `messages`→`input`→`prompt`，无文本内容时 400 直接点名可收字段; ② 新增 `POST /v1/messages/count_tokens` → Anthropic 形状 `{input_tokens}`，计数用 `buildAnthropicMessageList`(与 `/v1/messages` 同一个 builder ⇒ 预算与实际投喂同源，含 system 与 tool 定义); ③ `/v1/capabilities` 起 `endpoints:[{method,path,auth,note}]`(`auth` 由 `AuthRoutePolicy` 推导，不手抄) ⇒ 404 提示语有交付缝; ④ 两个计数端点都带 `tokenizer_backend: real|heuristic`，且 tokenizer 缺失时不再以 `modelNotFound` 404 掉一个 `/v1/models` 说 ready 的模型，而是回 heuristic 并标注; ⑤ 多轮 `messages` 走 chat template 全量计数(每轮控制 token 不再少算)。**已核(同会话输出)**: `make test-clt` = **2378 tests / 442 suites 全绿**(10-14，测试时间 ~45s；合同 `sdk=26.5 coreai=no metal=ok-probed`)，其中 `CountTokensWireShapeTests`(13) / `V1EndpointCatalogTests`(6) / `AnthropicRequestDecodeTests`(+3) 首次真跑并绿，另加 `CountTokensEndpointTests`(4 条 HTTP 级路由/错误契约，不需模型) 与 `MetalShaderLibraryTests`(7)；活体 `ocoreai serve`(port 8157，默认模型 `gemma-4-e2b-it-4bit`) + `curl` 三查全过 —— `POST /v1/count-tokens` 带 `messages`+`system` → 200 `prompt_tokens:43` `tokenizer_backend:"real"`；同端点 OpenAI `input:"hello world"` → 200 `prompt_tokens:12` `real`；`POST /v1/messages/count_tokens` 带 Anthropic text-block `system`(含 `cache_control`) → 200 `{"input_tokens":22,"tokenizer_backend":"real"}`(旧值 404)；`GET /v1/capabilities` → `endpoints` **33 行** == 同一正则扫 `ChatCompletionsRouter.swift` 得到的注册数 33，两个 count 端点均在列、`auth` 由策略派生。**顺带修掉两条「从没跑过的门」**: `V1EndpointCatalogTests` 的 repo root 用固定两跳 `deletingLastPathComponent()`，实际落在 `Tests/`，三条扫描断言全部 ENOENT 抛错(上一轮只跑了 `swiftc -parse`，语法绿把它掩盖了) —— 改成上溯直到找到路由文件本身(找到即证明仓库根)；`CountTokensWireShapeTests` 缺的 `try` 与 suite 内静态 helper 的 `Self.` 前缀补齐。**残留(不静默扩大范围)**: 计数值的绝对正确性仍以模型自带 tokenizer 为唯一权威，未与第三方实现对拍；`heuristic` 分支只在 tokenizer 缺失时生效，其估算精度没有独立断言。
