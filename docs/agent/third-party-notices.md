# Third-party notice composition

> The long form behind § *Build / Test / Lint* → "Distribution licenses" in `AGENTS.md`.
> Regenerate with `scripts/collect-third-party-licenses.sh`; texts live in
> `THIRD-PARTY-LICENSES/`, gated by `ThirdPartyNoticesTests` + `scripts/audit.swift_patterns.sh`
> (Class-I).
**Distribution licenses (CI-gated, 10-14):** the artifact is MIT **plus** third-party code under its own terms, and BSD-3 cl.1/cl.2 / Apache-2.0 §4 attach to the notice, so those texts must travel with the binary. Composition (every number grep-reproducible): Apple-derived = `git grep -l "Copyright 2026 Apple Inc" -- Sources` → **44** files, all carrying Apple's verbatim BSD-3 header (29 name `coreai-models`, the rest Apple-authored files from other Apple trees, e.g. the XGrammar C bridge); vendored headers under `Sources/lib/` = **1** (`dlpack.h`, dmlc/dlpack, Apache-2.0 — attribution lives in the collector's explicit `VENDORED` table, anything outside it fails); deps = **29 Apache-2.0 + 5 MIT**; codex = semantic reference only (Rust, not linked, nothing redistributed → no text ships). Metric warning: `git grep -il coreai-models -- Sources` = 58 is **not** the derived count — 29 of those hits carry no Apple copyright notice (they only mention the reference repo in a comment), while 15 BSD-3 files carry Apple's notice without naming coreai-models. Pipeline: `scripts/collect-third-party-licenses.sh` regenerates `THIRD-PARTY-LICENSES/` (38 files: `NOTICES.md` + `manifest.json` + one text per dep + Apple BSD-3 byte-compared against the `~/references/coreai-models` clone when present + the dlpack Apache text; **exits 1** if a dep text is missing, no checkouts are present, or a vendored holder is unattributed) → `scripts/bundle-licenses.sh <app>` copies it into `Contents/Resources/` and re-reads it *from inside* the bundle → called by `scripts/build-app.sh`. **Adding a dependency or vendoring a header ⇒ re-run the collector and commit its output.** Two gates keep it true: `ThirdPartyNoticesTests` (11 tests; needs no checkouts ⇒ gates every CI leg; pins `Package.resolved` ↔ manifest set equality, scan floors so a narrowed scan can't fake a pass) and `scripts/audit.swift_patterns.sh` **Class-I** (missing NOTICES.md, malformed rightsholder line, unattributed vendored file). GUI surface: Settings → About → Third-Party Notices, backed by `Core/ThirdPartyNotices.swift`; when texts are absent the panel says so, it never renders blank.
