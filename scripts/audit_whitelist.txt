# ocoreai audit whitelist -- one exemption per line, format:
#
#     path-token :: line-shape :: count
#
# `path-token` is matched against the hit line's path, `line-shape` is an ERE matched against
# the hit line, and `count` is how many lines in Sources/ that pair excuses RIGHT NOW. The gate
# recomputes count before any class runs and goes red on a mismatch: too high means a new
# instance appeared (fix the code, do not raise the number), zero means nothing is left to
# excuse (prune the entry -- an unused exemption is a loaded door that excuses the next defect).
# An entry with no comment above it is not a whitelist, it is a cover-up: say what the pattern
# matches and why that is not the defect.
#
# The previous format was one bare path per line, read by every class as a `-F` substring match.
# Measured on 10-26: 4 of its 5 entries excused 0 lines today while blinding 6,478 lines
# (of 103,864) from five classes at once, and two classes ran at a 100% exemption rate --
# which is the same shape Class-B was rewritten for on 10-15.

# EngineInference: the only empty catches in the tree are Task.sleep backoff inside a polling
# loop. sleep throws exactly one thing -- cancellation -- and both loops check cancellation on
# their own condition, so the throw is the loop's exit path, not a swallowed error. A logger
# call here would be noise, not signal (AGENTS.md: no wrapper or try? around code that cannot
# fail; same logic applies to catch).
EngineInference.swift :: try await Task\.sleep :: 2

# URL(string:)! on a compile-time https constant: the literal cannot fail to parse, and turning
# it into an Optional to satisfy a scan would add unwrapping clutter to code that has no nil
# path (the exact defensive clutter AGENTS.md forbids). What stays red: URL(string: someVariable)!
# -- a force unwrap over dynamic input, which is the crash this class exists to catch. Three
# constants, three entries, so a fourth constant has to be a deliberate act.
Application.swift :: URL\(string: "https:// :: 1
UpdateCheck.swift :: URL\(string: "https:// :: 1
NetworkSensor.swift :: URL\(string: "https:// :: 1

# MLXModelLoader owns MLX.Memory.cacheLimit -- 256 MB, and the app boot's other write (a 70 GB
# scheduler budget on a 128 GB host) used to win the race, so the log claimed a cache ceiling
# that never applied while a budget-sized cache measured ~2x slower. Class-H exists to keep a
# second writer from appearing, so the exemption names the owner's own line, not its file:
# another `Memory.cacheLimit =` anywhere in MLXBridge.swift now goes red.
MLXBridge.swift :: MLX\.Memory\.cacheLimit = 256 :: 1

# OpenAPIDocument: "3.1.0" is the OpenAPI *spec* version this document is written against, a protocol
# choice like a wire version — not a release number. Class-G exists because About, /metrics and MCP each
# froze the app version while v0.1.6 was on the wire; the app version appears nowhere in this file
# (`info.version` reads `AppInfo.shortVersion`), and probe 42 §4 asserts the served document's version
# equals the same binary's own `--version`, so a frozen app version would go red where it would matter.
OpenAPIDocument.swift :: specVersion = "3\.1\.0" :: 1
